Developer Integration Quickstart

Use your API Key in the X-API-Key header to query databases and interact with storage buckets from JavaScript, Python, or cURL:

1. Query Database by Unique ID
curl -X POST http://localhost:7331/api/v1/database/<YOUR_DB_ID>/query \ -H "X-API-Key: <YOUR_API_KEY>" \ -H "Content-Type: application/json" \ -d '{"sql": "SELECT * FROM leads LIMIT 10;"}'
2. Upload File to Storage Bucket by Unique ID
curl -X POST http://localhost:7331/api/v1/storage/<YOUR_BUCKET_ID>/upload \ -H "X-API-Key: <YOUR_API_KEY>" \ -F "file=@document.pdf"
